# Проектный план: iogrpc (gRPC runtime на C23 для iohttp)

## 1. Обзор проекта
`iogrpc` — это высокопроизводительная реализация gRPC-сервера на языке C23, спроектированная специально для экосистемы `ioplane`. Библиотека использует `io_uring` через `iohttp` для асинхронного сетевого взаимодействия и `nghttp2` для обработки протокола HTTP/2.

## 2. Архитектура и дизайн
- **Нативность для C23**: Полное использование стандарта ISO/IEC 9899:2024.
- **Транспортный уровень**: Интеграция с `iohttp` и `nghttp2`. Обработка gRPC-стримов поверх HTTP/2 DATA-фреймов.
- **Модель памяти**: Арена-аллокаторы (Arena allocators) для управления памятью каждого отдельного вызова (per-call arena), обеспечивающие высокую скорость и отсутствие фрагментации.
- **Безопасность**: Интеграция с `wolfSSL` для TLS 1.3 и ALPN.
- **Кодогенерация**: Специализированный плагин `protoc-gen-iogrpc-c` для генерации строго типизированных интерфейсов на C.

## 3. Среда разработки и зависимости
В качестве базового окружения используется `oraclelinux:10` (через Podman). Основные версии компонентов:
- **Компиляторы**: GCC 15 (gcc-toolset-15), Clang 22.1.0.
- **Build System**: CMake 4.2.3.
- **Библиотеки**:
    - `liburing`: 2.14
    - `nghttp2`: 1.68.0
    - `wolfSSL`: 5.8.4
    - `protobuf`: 29.3 (C++) для кодогенератора
    - `protobuf-c`: 1.5.1 для runtime
    - `unity`: 2.6.1 для тестирования

## 5. План тестирования
- **Unit-тесты**: На Unity для каждого внутреннего модуля (фрейминг, аллокаторы, статус).
- **Interop-тесты**: Тестирование совместимости с `grpcurl`, а также клиентами на Go и Python.
- **Нагрузочные тесты**: Использование `ghz` для измерения RPS и задержек (p99).
- **Статический анализ**: `clang-tidy`, `cppcheck`, `PVS-Studio`.
- **Санитайзеры**: ASan, TSan, MSan на этапе CI.
